ChecklistItem Object Pattern

Renders individual checklist items with all dynamic data attributes:

  • ✓ Item ID
  • ✓ Room assignment
  • ✓ Category
  • ✓ Hours estimate
  • ✓ Difficulty level
  • ✓ Label text
  • ✓ Checked state

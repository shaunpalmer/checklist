## What AysProductionRateSettings Does

**Single component handles**:
- ✅ Light & Heavy classification selection
- ✅ Standard rate display (defaults: 400 sq ft/hr or 330 sq ft/hr)
- ✅ Custom rate input with validation
- ✅ Unit selection (sq ft/hr or sq m/hr)
- ✅ Auto-conversion between units
- ✅ localStorage persistence ("Save as my default")
- ✅ Real-time validation (warns if <100 or >1000)
- ✅ Clean HTML + CSS styling

**Output**:
```javascript
{
  classification: 'light',
  use_custom_rate: true,
  production_rate: 450,
  production_unit: 'sq_ft_per_hour'
}
```

## Production Rate Usage

**In AysChecklistFormFactory**:

```javascript
// Light commercial: 5,000 sq ft
const productionRate = settings.production_rate; // User configured, e.g., 400
const propertySize = 5000;
const multiplier = 1.0; // Light = basic items

const laborHours = (propertySize / productionRate) * multiplier;
// = (5000 / 400) * 1.0 = 12.5 hours

// Heavy commercial: 10,000 sq ft
const multiplier = 1.25; // Heavy = mixed difficulty
const laborHours = (10000 / productionRate) * multiplier;
// = (10000 / 400) * 1.25 = 31.25 hours
```

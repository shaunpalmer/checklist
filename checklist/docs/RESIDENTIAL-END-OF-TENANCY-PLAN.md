# Residential + End of Tenancy Coverage Plan

## Goal
Create a complete, structured checklist that covers residential (furnished) and end of tenancy (empty) cleaning, with clear add-ons and room variants.

## Scope
### Residential (furnished)
- Base residential checklist (light/maintenance).
- Deep residential add-ons (room variants and extra tasks).
- Movable items and related tasks are included (beds, furniture, decor).

### End-of-Tenancy (empty)
- Built-in fixtures only:
   - Cupboards and wardrobes
   - Shelves
   - Appliances
   - Skirting boards and trims
   - Windows
   - Floors
- Excludes all movable items and related tasks:
   - Making beds
   - Polishing furniture
   - Knick-knacks or decorations
   - Lampshades or loose items

## Source References
- Residential room definitions: RESIDENTIAL-ROOM-DEFINITIONS.md
- Current checklist: thelist.md

## Plan
1. Inventory current checklist sections and tasks.
2. Map each section to residential room categories and variants.
3. Identify missing room types (laundry, utility, basement, outdoor, garage, etc.).
4. Split tasks into:
   - Residential (furnished)
   - End-of-Tenancy (empty)
5. Filter end-of-tenancy tasks to built-in fixtures only and remove movable-item tasks.
6. Draft add-on sections:
   - Deep Residential Add-Ons
   - End-of-Tenancy Add-Ons (empty-only scope)
7. Validate that each room type has a baseline task set and variant-specific notes.
8. Produce a final consolidated checklist with optional add-ons.

## Open Questions

- Do you want separate checklists for light vs deep, or a single base list with add-ons?
- Any compliance items (keys, access, alarms, photos) that must be required?

## Deliverables
- A gap analysis summary.
- A revised checklist for residential (furnished).
- A revised checklist for end-of-tenancy (empty) with built-in fixtures only.
- An add-on section for deep residential tasks.

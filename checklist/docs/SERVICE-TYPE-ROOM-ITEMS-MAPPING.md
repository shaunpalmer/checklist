# Service Type → Room Sections Mapping

**Purpose**: Define exactly what rooms and sections should be generated for each service type  
**Used By**: Hour 1-3 Sprint (ITEM_DEFINITIONS.js, ROOM_METADATA.js)  
**Status**: Specification (guides what goes into AysDisclosureRoomCard components)

---

## Why This Matters

The AysDisclosureRoomCard receives a list of items. But **which items should be in that list** depends on:
1. **Service Type** (EOT vs Residential vs Commercial)
2. **Room Type** (Bedroom vs Bathroom vs Kitchen)
3. **Variant** (Master vs Guest; Family vs Ensuite; Full vs Compact)
4. **Sub-features** (Double shower, oven, laundry, etc.)

Without this mapping, we build the wrong items into the cards.

---

## 🏠 END OF TENANCY (EOT) Service Type

**Philosophy**: Empty property, deep clean before handover. Tenant's deposit depends on this. **High scrutiny, thorough.**

### Fixed Rooms (Always Generated)
- **Living Room** (single card)
- **Kitchen** (single card)
- **Hallway / Stairs / Landing** (single card)
- **Entryway/Foyer** (single card)
- **Deep Cleaning** (single card - special items like ceiling decobing)

### Dynamic Rooms (Generated by Property Size)
- **Bedrooms**: Based on number selected (1-7)
  - Master Bedroom variant
  - Guest Bedroom variant
- **Bathrooms**: Based on number selected (1-5)
  - Family Bathroom variant
  - Ensuite variant
  - Single Toilet variant

### Optional Rooms (User selects if applicable)
- **Laundry Room** (if home has laundry facilities)
- **WC** (if separate toilet from bathroom)
- **Garage/Shed** (extra surcharge)

### Sample EOT Rooms (3-bed, 2-bath example)
```
Room Cards Generated:
├─ Living Room (1 card, ~7 items)
├─ Kitchen (1 card, ~9 items) 
├─ Hallway / Stairs / Landing (1 card, ~5 items)
├─ Entryway (1 card, ~4 items)
├─ Bedroom 1 - Master (1 card, ~8 items)
├─ Bedroom 2 - Guest (1 card, ~7 items)
├─ Bedroom 3 - Guest (1 card, ~7 items)
├─ Bathroom 1 - Ensuite (1 card, ~10 items)
├─ Bathroom 2 - Family (1 card, ~10 items)
└─ Deep Cleaning Special (1 card, ~6 items)

Total: 10 cards, ~73 items
```

### EOT Item Differences vs Residential

| Item Type | EOT | Residential |
|---|---|---|
| **Walls** | Spot cleaning, mark removal | Light dusting only |
| **Baseboards** | Wipe all (detail level) | Quick wipe |
| **Ceiling** | Cobweb removal (decobing) | NOT included |
| **Windows** | Clean inside & out, sills | Clean inside only |
| **Carpet** | Deep vacuum, stain check | Quick vacuum |
| **Under furniture** | Move & clean | Leave as-is |
| **Appliances** | Inside oven, fridge back | Outside wipe only |
| **Bathroom grout** | Scrub & detail | Quick wipe |
| **Light fixtures** | Clean/dust all | Switch only |

## 🏡 RESIDENTIAL Service Type

**Philosophy**: Occupied home, routine maintenance cleaning. Tenants present, family friendly. **Respects privacy, lighter touch.**

### Fixed Rooms (Always Generated)
- **Living Room / Dining Room** (single card)
- **Kitchen** (single card)
- **Hallway** (single card)

### Dynamic Rooms (Generated by Property Size)
- **Bedrooms**: Based on number selected (1-7)
  - Master Bedroom variant
  - Guest Bedroom variant
  - Child's Room variant
  - Nursery variant
- **Bathrooms**: Based on number selected (1-5)
  - Family Bathroom variant
  - Ensuite variant
  - Single Toilet variant

### Optional Rooms (User selects if applicable)
- **Laundry Room** (if separate room)
- **WC** (if separate toilet)
- **Home Office** (if dedicated space)
- **Garage** (light clean)

### Sample RESIDENTIAL Rooms (4-bed, 2-bath example)
```
Room Cards Generated:
├─ Living Room / Dining Room (1 card, ~6 items)
├─ Kitchen (1 card, ~8 items)
├─ Hallway (1 card, ~3 items)
├─ Bedroom 1 - Master (1 card, ~6 items + change linens option)
├─ Bedroom 2 - Guest (1 card, ~6 items)
├─ Bedroom 3 - Child's Room (1 card, ~6 items + toy storage)
├─ Bedroom 4 - Nursery (1 card, ~6 items + crib, changing table)
├─ Bathroom 1 - Family (1 card, ~9 items)
├─ Bathroom 2 - Ensuite (1 card, ~9 items)
└─ Laundry Room (1 card, ~5 items)

Total: 10 cards, ~64 items
```

### RESIDENTIAL Item Differences vs EOT

| Item Type | Residential | EOT |
|---|---|---|
| **Walls** | Light dust only | Spot clean + mark removal |
| **Baseboards** | Quick wipe | Detailed wipe |
| **Ceiling** | NOT included | Cobweb removal included |
| **Windows** | Inside only | Inside + outside + sills |
| **Under furniture** | Leave as-is | Move & clean underneath |
| **Linens** | **Change sheets (optional multi-select)** | Strip only |
| **Appliances** | Outside wipe | Inside detail (oven, fridge) |
| **Bathroom grout** | Quick wipe | Scrub detail |
| **Personal items** | Work around them | Property is empty |

### Additional RESIDENTIAL Feature
- **Change linens checkbox** (Master bedroom) - different from EOT strip

## 🏢 COMMERCIAL Service Type

**Philosophy**: Office spaces, shared facilities. Sanitation focus, efficiency metrics. **Different room types entirely.**

### Fixed Rooms (Always Generated)
- **Reception / Lobby** (1 card)
- **Hallway / Common Areas** (1 card)
- **Bathrooms** (shared facilities)

### Dynamic Rooms (Based on Office Layout)
- **Meeting Rooms / Offices**: Based on count selected (1-20)
  - Small Office variant
  - Medium Office variant
  - Large Conference Room variant
- **Lunch Room / Kitchenette** (if present)
  - Basic variant
  - Full variant

### Sample COMMERCIAL Rooms (8 offices, 2 bathrooms, 1 lunch room example)
```
Room Cards Generated:
├─ Reception / Lobby (1 card, ~4 items - commercial focus)
├─ Hallway / Common Areas (1 card, ~3 items)
├─ Office 1 - Small (1 card, ~4 items)
├─ Office 2 - Small (1 card, ~4 items)
├─ Office 3 - Medium (1 card, ~5 items)
├─ Office 4 - Medium (1 card, ~5 items)
├─ Office 5 - Large Conference (1 card, ~6 items)
├─ Office 6 - Small (1 card, ~4 items)
├─ Office 7 - Medium (1 card, ~5 items)
├─ Office 8 - Medium (1 card, ~5 items)
├─ Bathroom 1 - Multi Stall (1 card, ~8 items - commercial fixtures)
├─ Bathroom 2 - Single Stall (1 card, ~7 items)
└─ Lunch Room - Full (1 card, ~7 items - commercial appliances)

Total: 13 cards, ~68 items
```

### COMMERCIAL Item Differences (Unique to Commercial)

| Area | Items | Notes |
|---|---|---|
| **Bathrooms** | Sanitizer dispensers, paper towel refill, trash emptying | Different from residential |
| **Lunch Room** | Commercial microwave, commercial fridge, dishwashing station | Larger appliances |
| **Desks** | Keyboard/mouse sanitize, desk clear & wipe | Per-office items |
| **Floors** | Vacuuming + spot mop (higher traffic) | Different focus |
| **Baseboards** | Quick touch (commercial aesthetic) | Less detailed |
| **Walls** | Scuffs only (high traffic areas) | Not comprehensive |

## Hour 1-3 Sprint: What To Build

When building ITEM_DEFINITIONS.js, structure it as:

```javascript
const ITEM_DEFINITIONS = {
  'eot': {                           // Service type
    'living_room': {                 // Room type
      'basic': [                     // Variant (EOT only has 'basic')
        { itemId: 'living-carpet', label: 'Carpet Vacuum', ... },
        { itemId: 'living-tile', label: 'Tile cleaned', ... },
        // ... ~7 items total
      ]
    },
    'kitchen': {
      'basic': [ ... ~9 items ... ]
    },
    'bedroom': {
      'master': [ ... ~8 items ... ],
      'guest': [ ... ~7 items ... ]
    },
    'bathroom': {
      'family': [ ... ~10 items ... ],
      'ensuite': [ ... ~10 items ... ],
      'single_toilet': [ ... ~5 items ... ]
    },
    // ... more rooms
  },
  
  'residential': {
    'living_room': {
      'basic': [ ... ~6 items (lighter) ... ]
    },
    'kitchen': {
      'basic': [ ... ~8 items (outside appliances only) ... ]
    },
    'bedroom': {
      'master': [ ... ~6 items + "change_linens" ... ],
      'guest': [ ... ~6 items ... ],
      'child_room': [ ... ~6 items + toy_storage ... ],
      'nursery': [ ... ~6 items + crib_changing_table ... ]
    },
    // ... more rooms
  },
  
  'commercial': {
    'office': {
      'small': [ ... ~4 items ... ],
      'medium': [ ... ~5 items ... ],
      'large': [ ... ~6 items ... ]
    },
    'bathroom': {
      'single_stall': [ ... ~7 items (commercial) ... ],
      'multi_stall': [ ... ~8 items (commercial) ... ]
    },
    // ... more rooms
  }
};
```

**Key difference**: Items change by service type AND variant.

## Decision: Which Service Type for Hour 1-3?

**Recommend**: Build **EOT complete** in Hour 1-3 (3-bed, 2-bath example)
- Highest item count (teaches system how to scale)
- Most detailed (tests all item types)
- Can reuse for Residential (just fewer items per category)
- Commercial needs different room types (defer to Hour 4)

**First 3-hour sprint output**:
```
✅ ITEM_DEFINITIONS.js → eot service type complete
✅ ROOM_METADATA.js → eot room definitions
✅ Room classes instantiate correctly with ~73 items
```

Then Hour 4-6 adds `residential` and `commercial` services.
